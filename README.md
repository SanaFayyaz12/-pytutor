## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- OpenAI API key (optional - uses mock responses)

### Installation

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/Pytutor-AI-Chatbot.git
cd Pytutor-AI-Chatbot

# Install dependencies
npm install

# Install backend dependencies
cd server && npm install && cd ..

# Create .env file
echo "OPENAI_API_KEY=sk-your-api-key" > server/.env
echo "PORT=5001" >> server/.env
```

### Running Locally

**Terminal 1 - Backend:**
```bash
cd server
npm start
```

**Terminal 2 - Frontend:**
```bash
npm start
```

Visit: `http://localhost:3000` 🎉
